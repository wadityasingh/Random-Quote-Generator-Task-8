# QuoteFlow — Daily Inspiration & Curated Wisdom

QuoteFlow is a modern, responsive **Random Quote Generator** web application built using pure **HTML5**, **CSS3**, and **vanilla JavaScript**. Designed with an editorial white layout and a deep navy blue (`#1E3A8A`) and vibrant orange (`#F97316`) accent theme, QuoteFlow provides timeless wisdom from history's greatest thinkers with author profile avatars, real-time like counters, native sharing, category filtering, and persistent favorites.

---

## Features

- **Instant Random Inspiration**: Generates fresh, non-repeating wisdom on demand with a smooth 120ms fade-and-slide transition.
- **Author Profile Badges & Designations**: Every quote features the author's name, historical/contemporary title, and a dual-tone circular avatar with monogram initials and vibrant gradient styling.
- **Interactive Like Counter**: Like quotes directly with an animated heart button and real-time like counters that persist in `localStorage`.
- **Multi-Platform Sharing**: Share quotes to **WhatsApp**, **X (Twitter)**, **LinkedIn**, or copy beautifully formatted text with a single click.
- **Best Quotes of All Time**: A dedicated curated showcase of timeless masterpieces (Dr. A.P.J. Abdul Kalam, Steve Jobs, Marcus Aurelius, Maya Angelou, Albert Einstein, and Leonardo da Vinci) that can be copied, liked, or loaded onto the main stage.
- **Thematic Category Filters**: Explore quotes filtered by **All Themes**, **Motivation**, **Success**, **Life**, or **Wisdom**.
- **Saved Favorites Library**: Bookmark quotes to your personal library stored in the browser, with one-click copying and easy removal.
- **Accessibility & Responsive Design**: Semantic HTML5 elements, ARIA attributes, skip link, keyboard spacebar shortcut, and smooth responsiveness across mobile, tablet, and desktop screens.

---

## Technologies Used

- **HTML5**: Semantic layout elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<dialog>`, `<blockquote>`, `<footer>`).
- **CSS3**: CSS Custom Properties, Flexbox, CSS Grid, media queries, and hardware-accelerated compositor transitions (`opacity`, `transform`).
- **JavaScript (ES6+)**: Clean modular event listeners, event delegation, safe `textContent` rendering, and browser `localStorage`.

---

## How to Run Locally

1. Save `index.html`, `style.css`, and `script.js` in a folder on your computer.
2. Double-click `index.html` to open it in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox), or open the folder in Visual Studio Code and launch with **Live Server**.
